# Registration Form Project

A simple registration form built using HTML, CSS, and JavaScript. This project includes real-time form validation for Name, Email, and Password fields.

## Features

* Name field validation
* Email format validation
* Password minimum 6-character validation
* Real-time error messages
* Submit button disabled until all fields are valid
* Simple and responsive form design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Purpose

This project was created to practice JavaScript form validation, user input handling, DOM manipulation, and basic front-end development.
